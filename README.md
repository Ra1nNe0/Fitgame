# FitQuest — приключение в движении

Пиксельная фитнес-игра на Unity 6: герой Фит бежит через четыре мира к замку Лорда Лени,
а управляет им сам игрок — движениями тела перед веб-камерой.
Учебный проект по дисциплине «Управление IT-проектами», тема №3 «AI-Фитнес: Приключение».

## Возможности

- **4 движения**, распознаваемых нейросетью: прыжок, присед, удар, руки вверх. Качество выполнения
  (глубина приседа, высота прыжка, прямота рук) влияет на очки; недоделанное движение не засчитывается.
- **12 уровней в 4 мирах** (лес, пещера, вулкан, замок), 4 босса, режим «Марафон».
- **Ритм-баттл** в стиле Friday Night Funkin': босс показывает фразу стрелок, игрок повторяет её позами
  точно в такт — рука влево/вправо, руки вверх, присед (обе руки в стороны — две стрелки сразу).
  4 песни против 4 боссов, 3 сложности, длинные ноты, оценки S–D, автоподбор задержки камеры.
- **Интеллектуальная механика №1 (AI):** MediaPipe Pose Landmarker (33 точки тела) + собственный
  классификатор движений с калибровкой и оценкой качества.
- **Интеллектуальная механика №2:** адаптивная сложность — темп и частота связок подстраиваются
  под успешность и качество движений игрока; при последней жизни игра помогает сердцем.
- Обучение с помощником Пульсом, тест AI с отчётом (точность, матрица ошибок), AI-панель (F1).
- Монетизация freemium: образы и бусты за монеты, пакеты монет и FitQuest Premium (демо-оплата),
  реклама с вознаграждением.
- Сохранение прогресса, статистика тренировок (движения, калории), 16 достижений, таблица рекордов,
  журналы забегов в CSV.
- Музыка и звуки синтезируются в коде, графика нарисована скриптами (палитра ENDESGA 32).

## Запуск

**Готовая игра:** распаковать `FitQuest_Windows.zip` и запустить `FitQuest.exe` — Python не нужен,
сервер камеры (`pose_server.exe` с моделью) упакован внутрь и запускается игрой сам.

**Из исходников:**

1. Открыть папку `FitQuest/FitQuest` в Unity 6 (6000.6.5f1) и нажать Play.
2. Для управления камерой нужен Python 3 (python.org, галочка «Add python.exe to PATH»).
   Игра сама запускает сервер распознавания; первый запуск ставит пакет mediapipe (несколько минут).
3. Сборка для Windows: `Tools/pose_build/build_pose_server.bat` (упаковывает сервер камеры через PyInstaller),
   затем в Unity меню FitQuest → «Собрать Windows» (результат в `FitQuest/FitQuest/Builds/FitQuest_Windows`).

| Клавиша | Движение | Против чего |
|---|---|---|
| Пробел | Прыжок | шипы, бревно, камень босса |
| S | Присед | летучая мышь, огненный шар |
| D | Удар | слизень, ящик, синий шар босса |
| W | Руки вверх | лиана над ямой, монеты, сердце |

Enter — подтверждение, Esc — пауза/назад, F1 — AI-панель. Shift — неточное движение, Ctrl — слабое (для отладки).

В ритм-баттле: стрелки или WASD (←/A — рука влево, ↓/S — присед, ↑/W — руки вверх, →/D — рука вправо).

## Архитектура

```
Игрок → Веб-камера → pose_server.py (MediaPipe, Python) ──UDP──▶ PoseLink → PoseMotionClassifier ─┐
Игрок → Клавиатура → KeyboardMotionSource ─────────────────────────────────────────────────────────┤
                                                                                     MotionHub ◀────┘
                                                                                         │
             App (экраны, магазин, реклама) ◀── GameManager (забег, очки, боссы) ◀───────┘
                                                   │            │
                                     DifficultyDirector    SaveData (profile.json, логи CSV)
```

## Структура

- `FitQuest/FitQuest/Assets/Scripts/Motion` — движения: камера, классификатор, клавиатура.
- `.../Scripts/Core` — приложение, забег, уровни, сохранение, магазин, достижения, музыка, звук.
- `.../Scripts/Gameplay` — герой, препятствия, боссы, фон, адаптивная сложность.
- `.../Scripts/UI` — интерфейс и экраны.
- `.../Assets/StreamingAssets/PoseServer` — сервер распознавания позы.
- `.../Assets/Resources/Art` — графика. `Tools/art` — скрипты, которыми она нарисована.
- `Tools/ai_tests` — автотесты классификатора движений и поз ритм-режима на синтетических данных и их результаты.

## Сторонние материалы
